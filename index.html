The 30 symbols

Every base‑900 digit is a pair (top symbol, bottom symbol).

Itti Pronunciation: Every 30-digit symbol has its own click. A base-900 digit is made of two 30-digit symbols, so it receives two clicks (e.g., 616 = Top 20 + Bottom 16 → click + ins · click + uns). The optional "n" bridge can be used between syllables if it helps the speaker.
Encoding used: for a base‑900 digit d, the top symbol is ⌊d / 30⌋ and the bottom symbol is d mod 30, so d = 30·top + bottom.
Strokes: 10–19 use 1 horizontal cut (2 strokes). 20–29 use 2 cuts (3 strokes). Most numbers use a "Y" shape cut, but 1 and 3 use horizontal cuts to preserve their natural shape.
